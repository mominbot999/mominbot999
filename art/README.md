# Shan Shui background

A 1920×1080 Chinese ink-wash landscape (山水): misty mountains, vermilion sun, plum blossom
branch, cliff pavilion and pine, fishing boat, vertical calligraphy 山水清音 and a 墨韵 seal.

Drawn with [VectorCraft](https://github.com/storytold/vectorcraft) through its MCP server
(`vectorcraft-cli mcp --headless`).

| File | What |
|---|---|
| `china-shanshui.png` | 1920×1080 |
| `china-shanshui@2x.png` | 3840×2160 |
| `china-shanshui.svg` | Vector, text outlined |
| `china-shanshui.vectorcraft` | Editable VectorCraft document |
| `china_art.py`, `vc.py` | The script that draws it |

Regenerate: `VECTORCRAFT_CLI=/path/to/vectorcraft-cli python3 china_art.py out/china-shanshui`
